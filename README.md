## Функція варіанта

`delivery_cost(weight_kg, same_city)` повертає вартість доставки в гривнях (ціле число).

- База - 40 грн (включає перший кілограм).
- Кожен **повний** кілограм понад 1 кг додає 15 грн (2,5 кг → 1 повний кг понад перший → +15).
- Якщо доставка в своєму місті - знижка 20 % від підсумку.
- Вага 0, від'ємна, нескінченна, NaN або не число, а також `same_city` не типу `bool` - `ValueError`.
